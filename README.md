Dashboard analítico desenvolvido no Power BI como parte do desafio de projeto da DIO. Inclui tratamento de dados com Power Query, modelagem e criação de métricas em DAX.
# 📊 Dashboard de Análise de Dados Financeiros - Power BI

> **Projeto de Data Analytics desenvolvido durante o Desafio de Projeto da DIO (Digital Innovation One).**

---

## 📝 Descrição do Projeto

Este relatório foi desenvolvido com o objetivo de analisar o desempenho de vendas e lucros de forma detalhada, intuitiva e focada na **Experiência do Usuário (UX/UI)**. 

O painel permite navegar entre diferentes perspectivas de negócios através de um menu lateral interativo, facilitando a tomada de decisão com base em dados.

---

## 🎨 Principais Funcionalidades e Design (UX/UI)

- **Menu de Navegação Lateral:** Navegação fluida entre 3 páginas completas (*Sales*, *Profit* e *Report*).
- **Consistência Visual:** Paleta de cores em tons de azul e cinza para melhor legibilidade e contraste.
- **Ordenação Cronológica:** Gráficos com eixos temporais organizados de Janeiro a Dezembro.
- **Elementos de Célula (Cell Elements):** Tabelas e matrizes com *Barras de Dados* condicionais em azul suave para destaque rápido das métricas.
- **Layout Limpo:** Eliminação de elementos redundantes e foco na hierarquia visual dos KPIs.

---

## 🛠️ Tecnologias e Ferramentas Utilizadas

- **Power BI Desktop:** Construção dos visuais, layouts e navegação.
- **Power Query (ETL):** Limpeza, transformação e tratamento da base de dados.
- **DAX (Data Analysis Expressions):** Criação de medidas calculadas e agregações.
- **Visual Customizado:** Utilização do *ChicletSlicer* para botões e segmentações de dados.

---

## 📑 Páginas do Dashboard

1. **Sales (Vendas):** Visão geral do volume de vendas por período, segmento e país.
2. **Profit (Lucro):** Análise detalhada da margem de lucro por trimestre, país e hierarquia de decomposição.
3. **Report (Relatório Detalhado):** Matriz e gráficos comparativos temporais entre *Sales* e *Gross Sales*.

---

## 🚀 Como Visualizar o Projeto

1. Baixe o arquivo `dashboard-analise-dados.pbix` disponível neste repositório.
2. Abra o arquivo no [Power BI Desktop](https://powerbi.microsoft.com/desktop/).
3. Utilize `Ctrl + Clique` nos botões do menu lateral para testar a navegação interativa entre as páginas.
